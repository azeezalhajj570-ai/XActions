🗺️ XActions Roadmap

Building the ultimate X/Twitter automation toolkit

✅ Completed

Core Features

  • Unfollow non-followers
  • Unfollow everyone
  • Detect unfollowers
  • New follower alerts
  • Account monitoring
  • Leave all communities
  • Auto-liker
  • Keyword follow
  • Smart unfollow
  • Follow engagers

  • CLI tool

Scrapers

  • Profile scraper
  • Followers scraper
  • Following scraper

  • Thread scraper
  • Media scraper

Q1 2026 (Jan-Mar)

Tweet Scheduling

Priority: 🔥 HIGH
Effort: Medium
Revenue: +$9/mo tier

Features:
- Write tweet → Pick date/time → Auto-posts
- Queue view (drag & drop reorder)
- Recurring tweets
- Thread scheduling
- Timezone support

Analytics Dashboard

Priority: 🔥 HIGH
Effort: Medium
Revenue: +$9/mo tier

Features:
- Follower growth chart
- Following/Followers ratio
- Engagement rate over time
- Best performing tweets
- Daily/weekly/monthly stats

AI Tweet Writer

Priority: 🔥 HIGH
Effort: Medium (needs OpenAI/Grok API)
Revenue: +$19/mo tier

Features:
- "Write a viral tweet about [topic]"
- Generate 5 variations
- Tone selector (funny, professional, controversial)
- Thread generator from long text
- Bio generator

Q2 2026 (Apr-Jun)

Thread Composer

Priority: HIGH
Effort: Easy
Revenue: Included in Pro

Features:
- Write long-form → Auto-splits into thread
- Preview thread layout
- Schedule thread
- Add images per tweet
- Numbering options (1/, 1/10, etc.)

Best Time to Post

Priority: Medium
Effort: Medium
Revenue: Included in Analytics

Features:
- Analyze your tweet performance by hour
- Follower activity analysis
- Recommended posting times
- Heatmap visualization

Engagement Leaderboard

Priority: Medium
Effort: Easy
Revenue: Included in Pro

Features:
- Who engages with you most
- Top repliers/likers
- Track engagement over time
- Export VIP list

Q3 2026 (Jul-Sep)

Competitor Tracking

Priority: Medium
Effort: Medium
Revenue: +$9/mo

Features:
- Track any account's follower growth
- See their top tweets
- Posting frequency analysis
- Compare side by side

Auto-Plug (Replies)

Priority: Medium
Effort: Easy
Revenue: Included in Pro

Features:
- Auto-reply to your own viral tweets
- Customizable plug templates
- Delay settings
- Engagement threshold trigger

CRM / Audience Tagging

Priority: Low
Effort: Hard
Revenue: Enterprise tier

Features:
- Tag followers (VIP, customer, lead)
- Notes on users
- Filter by tags
- Export segments

Q4 2026 (Oct-Dec)

Multi-Account Dashboard

Priority: Medium
Effort: Hard
Revenue: Enterprise tier ($49+/mo)

Features:
- Switch between accounts
- Unified analytics
- Cross-post to multiple accounts
- Team permissions

DM Automation

Priority: Low
Effort: Hard
Revenue: Enterprise tier

Features:
- Auto-welcome new followers
- DM campaigns
- Templates
- ⚠️ Risky - may violate ToS

API Access

Priority: Low
Effort: Medium
Revenue: Enterprise tier

Features:
- REST API for all features
- Webhooks
- Rate limits by tier
- API key management
